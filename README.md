# HotkeyManager — Windows 版 Ubuntu 风格自定义快捷键

在 Windows 11 上复刻 Ubuntu/GNOME「查看和自定义快捷键」界面的全局快捷键工具。

## ⚠️ 必须以管理员身份运行

启动时会自动弹出 UAC，请点「是」。原因：Windows 的 UIPI 机制禁止普通权限程序操作管理员窗口——不提权时热键在管理员窗口（如浏览器）上不触发、调整窗口会被拒绝（错误 5）。点了「否」仍可降级运行，但只能管理普通权限窗口。

## 下载

- 直接下载 `HotkeyManager.exe`（单文件，免安装）
- 或从 Releases 页面下载最新版本

## 使用方法

1. 双击 `HotkeyManager.exe`，UAC 点「是」
2. 双击任意一行 → 按下组合键 → 点「设置」
3. 点「+ 添加自定义快捷键」可绑定任意命令
4. 「移除」删除自定义项；「重置默认」恢复 47 条内置快捷键（需确认）
5. 托盘右键：暂停全部热键 / 开机自启 / 以管理员身份重启 / 退出

## 内存占用

- 常驻仅 1 个进程，空闲约 5–15 MB，CPU ≈ 0%
- 无第三方常驻服务，无 Electron / 浏览器内核
- 亮度调节调用 Windows 自带 PowerShell WMI，执行完即退出
- 对比：PowerToys 单个组件空闲即可占 200 MB+

## 基于什么改造

- 运行时：AutoHotkey v2.0.31（GPLv2，纯 Windows 原生自动化引擎）
- 界面与交互：仿 Ubuntu/GNOME 的「查看和自定义快捷键」分类列表
- 单文件 exe 由官方 Ahk2Exe 编译，内嵌 AHK 运行时

## 是否安全

- 完全本地运行，不联网、不上传任何数据
- 不写系统目录，配置仅保存在同目录 `HotkeyManager.ini`
- 仅在你点击「开机自启」时才创建启动项快捷方式
- 源码 `HotkeyManager.ahk` 可自行审查或重新编译
- 注意：编译型 AHK 程序可能被杀软误报，添加信任即可

## 已知限制

- 亮度仅对笔记本/一体机内置屏有效，外接屏需 DDC/CI 工具
- 系统保留组合（Win+L / Ctrl+Alt+Del / Ctrl+Shift+Esc）无法绑定
- 极少数 UWP 窗口（如系统设置）不支持程序化调整大小
